# 已有 Demo 的实现说明

源码：`demo/index.html`。纯 HTML/CSS/JavaScript，无外部资源或后端请求。

## 当前实现

- state：扎结点、折叠、深浅、默认半径、扎法、种子和模板。
- effectivePoints：对折或四折映射，同位置点去重。
- makeDye：逐像素计算留白遮罩与蓝色色阶，叠加可重现噪声及布纹。
- drawEditor：绘制白布、扎结与映射点；指针事件实现添加和拖动。
- history：最多 30 个参数快照；支持撤销、删除、清空和键盘操作。
- startDye / readyToUntie / untie / finishWork：制作过程及展开。
- previousWork / currentWork：两次作品对比。
- download：生成 768×768 的 PNG；预览为 260×260，编辑 Canvas 为 600×600。

初始化有四个扎结点。原始点上限 12，对折/四折可能增加映射点。选择一个点后，半径滑杆只修改该点；未选中时修改全部点。

## 当前限制

单文件中耦合了 DOM、算法、动画与状态。计算在主线程；作品使用 data URL 并只保留在内存；没有持久化、版本迁移或完整文化页面。四个模板是原创交互体验方案，不构成传统纹样档案。

屏幕上的染色与氧化是艺术化近似和过程动画，不是物理或化学预测。折叠使用平面镜像映射，不是布料三维仿真。

迁移时先保留现有功能，再逐步提取参数、引擎、状态和服务。不要为重构牺牲当前已经可操作的完整流程。
