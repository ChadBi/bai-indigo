# 产品范围与功能

## 产品定位

平台聚焦白族扎染，用网页交互表达扎结、防染、染色和展开纹样之间的关系。用户在数字空间完成一次创作，并带走自己的作品。文化内容随步骤、纹样与结果出现。

核心用户是初次接触扎染的学生、文化与设计爱好者；课堂演示也是使用场景。

## 六个模块

| 模块 | 功能 | 页面组织 |
|---|---|---|
| 染艺寻踪 | 工艺背景、地域、图案资料、分类与详情、来源 | 文化导览 |
| 一布一染 | 材料说明、步骤教学、防染原理示意、进入创作 | 工艺学习 |
| 掌上扎染 | 布面编辑、扎结、折叠、参数、浸染、氧化、拆线 | 统一创作页 |
| 纹样工坊 | 模板、自由布局、对称与间距、方案调整 | 与掌上扎染共用画布 |
| 染作生成 | 命名、对比、保存、导出、作品库与继续编辑 | 结果展示与作品页 |
| 白乡故事 | 相关图文故事、生活应用、来源、纹样关联 | 故事列表与详情 |

工艺术语与常见问题是学习页的辅助区，不另建大型系统。

## 第一版功能闭环

进入网站 → 认识或学习工艺 → 从模板或空白布开始 → 调整扎结与折叠 → 浸染和氧化 → 拆线展开 → 保存作品 → 再次编辑或对比 → 阅读相关文化。

草稿可恢复，作品可在同一浏览器中重新打开；成品下载为 PNG，创作方案支持文件导出，后续实现导入。

## 视觉与文案

- 靛蓝、白色与少量浅蓝；画布突出，操作面板集中，正文舒适可读。
- 保持可跳过的过程动画，兼容 reduced motion。
- 示例模板为四方纹、单花纹、折叠条纹、自由扎结，均属体验方案。
- 传统纹样与寓意从可靠资料中确定，保留来源与授权信息。
- 不使用后台管理系统式首页或过多嵌套卡片。
- 文案直接描述产品功能与文化，不说明文档写给谁、怎么阅读或作者如何写作。

## 后续扩展

文创预览、更多有来源的纹样、云端保存与跨设备使用。账号、社区、商城、AI 对话、三维或 VR 均不进入当前第一版。
