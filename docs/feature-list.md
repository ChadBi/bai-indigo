## 2. 掌上扎染

- [x] 白布编辑画布及实时染后预览。
- [x] 点击添加、选择和拖动扎结。
- [x] 删除选中扎结、清空布面。
- [x] 单个扎结与全部扎结的半径调整，范围 6%—24%。
- [x] 最多 12 个原始扎结，达到上限时提示。
- [x] 不折叠、对折、四折及折线展示。
- [x] 展示折叠映射点；拖动映射点时反算原始扎结位置。
- [x] 浅染、中染、深染三档颜色。
- [x] 最多 30 次有效撤销。
- [x] 一次拖动或连续调半径合并为一次撤销；选择及无变化操作不入历史。
- [x] 指针取消时回退未提交的编辑操作。
- [x] 添加按钮和扎结选择控件，支持键盘操作。
- [x] Ctrl/Cmd+Z 撤销、方向键移动、Delete/Backspace 删除、Escape 取消选择。
- [x] 260×260 Worker 预览，预览请求最多每 80ms 发起一次。
- [x] 取消旧请求并过滤过期结果；计算失败可重试。
- [x] 准备图像、浸染、氧化、等待拆线、展开、完成的制作流程。
- [x] 制作期间锁定参数和编辑操作。
- [x] 跳过浸染／氧化动画，仍保留拆线操作。
- [x] 减少动态效果模式下省略动画。
- [x] 制作中切换页面取消计算与动画，不登记未完成结果。
- [x] 完成后“再染一次”，继续编辑原方案。

- [x] 离开创作页时立即尝试保存已提交草稿。
- [ ] 多标签页同时编辑的冲突检测与合并。

**草稿和成品分别保存。** 选中点、撤销历史、动画进度与两次会话对比不持久化；成功保存的成品包含图像、参数和编辑元数据。清除网站数据会删除草稿与作品；500ms 草稿保存尚未提交时直接关页，最后一次修改可能丢失。
